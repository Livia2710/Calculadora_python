# Calculadora Desktop em Python

Aplicação desktop desenvolvida em **Python**, com interface gráfica moderna utilizando **Tkinter + ttkbootstrap**.
O projeto foi criado com foco em prática de **programação orientada a objetos**, eventos, layout responsivo e personalização visual.

## Preview
![Preview da aplicação](assets/calculadora.gif)

## Funcionalidades
- Operações matemáticas básicas (+, -, x, ÷)
- Potenciação(^)
- Uso de parênteses para expressões
- Limpar display e apagar último caractere
- Interface gráfica desktop
- Troca dinâmica de temas
- Exibição de imagem na interface

## Tecnologias Utilizadas
- Python
- Tkinter
- ttkbootstrap
- Pillow (PIL)

## Conceitos Explorados
- Programação Orientada a Objetos (POO)
- Manipulação de eventos e callbacks
- Organização de layout com `Frame` e `Grid`
- Atualização dinâmica de interface
- Avaliação de expressões matemáticas
- Gerenciamento de recursos para empacotamento
- Personalização visual e temas
